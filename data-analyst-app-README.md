# AI Аналитик данных

Веб-приложение на Streamlit, которое анализирует CSV-файлы с помощью LLM через API (Groq).

## Структура проекта

```
data-analyst-app/
├── app.py        # основной скрипт
└── README.md
```

## Как это работает

1. Пользователь загружает CSV-файл через веб-интерфейс
2. Опционально указывает инструкцию — на что обратить внимание
3. Приложение отправляет данные в Groq API (модель llama-3.3-70b-versatile)
4. LLM проводит анализ и возвращает структурированный отчёт
5. Результат отображается на странице

Приложение включает защиту от prompt injection — подозрительные инструкции блокируются.

## Установка и запуск

### 1. Установить зависимости

```bash
pip install streamlit requests pandas
```

### 2. Получить API-ключ

Зарегистрироваться на [console.groq.com](https://console.groq.com), создать API-ключ в разделе **API Keys**.

### 3. Вставить ключ в скрипт

В файле `app.py` найти строку:

```python
API_KEY = "сюда_вставь_свой_ключ"
```

И вставить туда свой ключ.

### 4. Запустить приложение

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## Пример работы

### Входные данные
CSV-файл с продажами: регион, продукт, количество, выручка, менеджер.

### Инструкция пользователя
"Обрати внимание на продажи по регионам и менеджерам"

### Результат
- Общее описание датасета
- Ключевые метрики (общая выручка, средний чек, топ регионы)
- Инсайты и закономерности
- Выводы и рекомендации

## Защита от Prompt Injection

Приложение фильтрует опасные инструкции. При обнаружении подозрительного текста возвращает предупреждение вместо запроса к LLM.
